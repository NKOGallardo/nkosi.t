# NKOSI T PORTFOLIO

A modern, responsive photography and videography portfolio website designed to showcase professional creative work, attract potential clients, and provide an easy booking experience.

---

## Project Overview

This website serves as the official online portfolio for **Nkosi T Photography & Videography**. It highlights photography collections, videography projects, services, client information, and booking options through a clean and visually engaging user experience.

The website is built using:

* HTML5
* CSS3
* Vanilla JavaScript
* GSAP Animations
* Responsive Design Principles
* SEO Best Practices

---
